# クロスフィルター

写真の光源に、クロスフィルター(Kenko STAR4 相当)の光条を後処理で足す Web ツールです。
単一の HTML(WebGL2)で動き、スマホのブラウザからそのまま使えます。サーバーもビルドもありません。

## 使い方

1. ページを開く(最初はサンプルの夜景が出ます)
2. 「写真を選ぶ」で写真を読み込む
3. リングを回して光条の角度を決め、「長さ」「強さ」「光を拾う明るさ」を調整する
4. 「保存する」→ 共有シートから写真に保存(iOS / Android)、または「ファイルとして保存」

写真を長押ししている間だけ元の写真に戻ります。「こまかい調整」には、広い明部を外す「点光源だけにする」、光条の色、虹色、裾の伸び、にじみがあります。設定はブラウザに記憶されます。

書き出しは最大約 1600 万画素(6000×4000 は 4899×3266 になります)、JPEG 品質 0.95。EXIF は残りません。

## 仕組み

1. 明るい部分を抜き出し、広い明部(空・壁・看板)を外して、光源の強さで重み付けする
2. 方向ごとに減衰させながら引き伸ばす。鋭く短い「芯」と、長く淡い「裾」の 2 成分
3. リニア空間で元の写真にスクリーン合成する

詳しくは `DESIGN.md`。試作版からの経緯と決定事項は `MEMORY.md`。

## 開発

```
npm install          # playwright-core だけ
npm test             # tests/run.cjs: smoke → profile → matrix → parity
```

テストは手元の Microsoft Edge を SwiftShader(ソフトウェア描画)で起動します。別のブラウザを使うときは `BROWSER_PATH` に実行ファイルを指定してください。結果は `test-results/` に画像と CSV で出ます。ソフトウェア描画なので 1 本あたり数分かかります。

- `tests/smoke.cjs` 390px 幅で読み込み → 書き出し、レイアウト
- `tests/profile.cjs` 黒地に白点 1 個で光条の断面を数値化(`legacy/cross-filter-v0.html` を渡すと試作版が測れます)
- `tests/matrix.cjs` 強さ × 光を拾う明るさ の 6 枚を並べた比較画像
- `tests/parity.cjs` プレビューと書き出しの一致、光源のない領域が元画像と一致
